Máy chủ Node.js (cổng 3600) tiếp nhận và thực thi theo chu trình an toàn:

  • • 3. Lưu CSDL: Ghi tức thì vào file JSON đĩa cứng và đồng bộ bảng SQL Server.
Thời gian xử lý < 15ms

Cơ Chế Cầu Nối Dual-Mode Client Bridge

cloud_done Chế Độ 1: Online Mode (Server Đang Chạy)

Ứng dụng gửi HTTP fetch trực tiếp lên Node.js REST API Server cổng 3600. Dữ liệu được ghi tức thì vào CSDL trung tâm và phản hồi kết quả trong < 20ms.

cloud_off Chế Độ 2: Offline Fallback (Mất Mạng / Tắt Server)

Khi máy chủ offline hoặc mất kết nối mạng, `TapHoaCore.api` tự động fallback sang IndexedDB (`TapHoaSoDB`) và LocalStorage. Thu ngân vẫn bán hàng bình thường không bị dừng lại.

TapHoaCore.api.getProducts()
async getProducts() {
  // 1. Kiểm tra server online
  if (await this.isServerOnline(600)) {
    try {
      const res = await fetch('/api/products');
      if (res.ok) return await res.json();
    } catch (e) {}
  }
  // 2. Tự động fallback an toàn
  return dalModule.getAllProducts();
}
* Đảm bảo tính liên tục của hệ thống bán lẻ theo tiêu chí Fault-Tolerant Enterprise System.
